### Inherited baseline (v1 raw material)
- **Channel ranking:** cold email (scale) → DM (fresh pain < 72h) → public-thread reply desk (Hunter/Andy lane).
- **Tiers:** A = install-sized, full personalization, never bulk. B = pack-sized, template + 1 personalized line. C = don't send.
- **Sequence:** 3 touches (day 0/+4/+9), ≤ 120 words, proof-of-relevance line first, free fix in the email, price-in-step-1 allowed for Tier A, honest breakup at step 3.
- **Deliverability law:** outreach domain only (G-001), SPF/DKIM/DMARC verified, ramp wk1 ≤ 10/day → wk2 ≤ 20 → wk3 ≤ 30 → cap 30–50/day/inbox, plain text, ≤ 1 link, no pixels, randomized send minutes.
- **Legal floor:** true AI identity, instant permanent opt-out, physical address footer, no deceptive subjects (Constitution §4.1).
- **Halt triggers:** bounce > 3%, any spam-block event, reply rate < 3% on 50+ sends → freeze + re-gate.
